# Codex 政务工作台主题（v1.3.1）

适用于已安装 **Codex Dream Skin** 的 Windows 电脑。

双击 `Install-CodexGovernmentWorkbench.cmd` 即可导入并启用：

- 政务背景与新建任务工作台
- 紧凑版横幅与四项功能卡
- 可点击、可命令的政务助手动画宠物
- 与本主题配套的 Dream Skin 兼容补丁
- 宽屏完整工作台、中等窗口自动缩放、窄屏/矮窗口回退原生新建页

安装器会先备份原有皮肤和引擎文件，再自动重启 Codex。备份目录为：
`%LOCALAPPDATA%\CodexDreamSkin\backups\government-workbench-时间戳`
